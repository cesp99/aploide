Privacy Policy

Our Eyed apps does not store any data about users.

Current Eyed apps are: "Eyed Out", "Eyed Pass", "Eyed Auth", "Eyed Tools".

"Eyed Pass", "Eyed Auth", and "Eyed Tools" are offline applications that do not require internet access.

"Eyed Pass" only uses the internet to load website icons

Eyed Out

Our browser "Eyed Out" does not store any data about users.

And we try to get the browser as private as possible, limiting also the websites that people uses to track you.

We created the browser based off WebKit so you can check more information about it on https://webkit.org/blog/category/privacy/

Third-Party APIs

Even tho our browser uses Third-Party APIs we (Aploide) keep the user information hidden during the API call.

Dark by Eyed™

Our extension "Dark by Eyed™" does not store any data about users.

The web extension runs completely offline sending no data to the cloud and not fetching any data from the cloud.

Where does Aploide gets website icons in their apps?

From DuckDuckGo public API.

The website icons we use in "Eyed Pass" and "Eyed Out" come from DuckDuckGo public API.

For more information visit their privacy policy.

Does eyed.to API store users IPs?

No, eyed.to API does not store users or visitors IPs.

The URL shortener (eyed.to) stores only the url to shorten and it's shortened version.

Does Eyed Search Suggestions API store users queries or IPs?

No, Eyed Search Suggestions API does not store users or visitors IPs nor queries.

The Suggestions API (ac.eyed.to) sends back results from a fixed elements database.
