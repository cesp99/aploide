15. Spettro by Eyed™ — Multi-Agent Coding Assistant

Spettro is a terminal-first multi-agent coding assistant distributed under the GPL-3.0 open-source license (the "CLI"). By using the CLI and by connecting it to the Backend operated by Eyed® Softwares, you agree to the following additional terms:

  1. Account and API key. Access to the Backend requires sign-in through our authentication provider on spettro.app. On completion we mint a ep_… API key and store only its hash. The plaintext key is shown to you exactly once and is never persisted server-side. You are responsible for keeping your API key secure and for all activity that occurs under your account.
  2. Local storage of the key. The CLI keeps your API key and any third-party provider keys you add in an encrypted keystore on your machine. The CLI is configured by a configuration file and by per-project .spettro/ directories in the repositories you open.
  3. Budget system. Each account is subject to a monthly credit limit based on LLM token usage. Once exhausted, the Backend returns HTTP 402 Payment Required for paid models. Budgets reset on the subscription's billing day; for free users without a subscription, budgets reset at the start of each calendar month.
  4. Acceptable use. You agree not to use Spettro to generate content that is illegal, harmful, or in violation of third-party rights, and to comply with Section 6 above. You are solely responsible for any content generated through your use of the service.
  5. Third-party LLM providers. The Backend routes every chat-completion request to one of the upstream model providers. The current set is Spettro (SuperFast, SuperSmart), Alibaba Cloud (default), MiniMax, and Crof AI; the per-call model aliases and real upstream names are subject to change. We are not responsible for the availability, accuracy, or content of responses generated by these providers. By using the Backend you acknowledge that your prompts and the model's responses are transmitted to the relevant upstream and processed under that provider's terms and privacy policy.
  6. Token accounting. The Backend records, for every successful inference, the model alias, token counts, the cost computed from our pricing table, the API key id used, and the timestamp. This row is the only server-side record of your activity; your prompts, conversation history, and tool output remain on your device.
  7. Available LLM models. The Spettro subscription grants access to a set of LLM models offered through the Backend, tiered by plan (free, lite, plus, pro, max). We reserve the right to add, remove, or change the availability of any specific model at any time, with or without prior notice. Access to a given model is not guaranteed for the entire duration of your subscription and may be revoked, added, or modified at our sole discretion.
  8. Local opt-in features. The CLI exposes optional, opt-in surfaces that you must turn on explicitly. Each runs entirely on your machine and makes its own outbound calls under your control:
    • /remote — exposes a local HTTP/SSE control plane gated by a one-time bearer token printed by the CLI.
    • /telegram setup <token> — long-polls the Telegram Bot API for messages from chats or usernames on your allowlist.
    • --headless — runs the agent over an HTTP/SSE control plane for use by external front-ends such as our iOS and Android apps.
    • --acp — runs the agent over stdio as an Agent Client Protocol agent for editors such as Zed.
    You are responsible for the security of any device, network or chat you expose through these surfaces.
  9. Agent Skills. The CLI reads skill manifests from local and per-project skill directories. Skills you install can run arbitrary code on your machine under the user account running the CLI; install only skills you trust.
  10. Background network calls. On startup the CLI makes a silent check for a newer version. No payload is sent. You can disable this by building the CLI from source with the version-check tag omitted.
  11. Open source. The Spettro CLI is distributed under the GPL-3.0 license. The Backend, the spettro.app web application, and any other hosted infrastructure are proprietary and are not covered by that license.

16. Spettro-Desktop (Linux & Windows)

Spettro-Desktop is the desktop application we distribute for Linux and Windows. It is a view over the CLI, which it runs as a subprocess via the Agent Client Protocol. By installing and using Spettro-Desktop you agree to the following:

  1. What it stores. Spettro-Desktop locally stores user preferences (CLI binary override, recent projects, cached configuration options), chat-session snapshots, and — if you enable the LAN phone relay — records of paired devices. It does not duplicate your API keys or any other secret held by the CLI.
  2. LAN phone relay. When you enable the LAN relay, Spettro-Desktop advertises a local network service, opens a port, and shows a QR code carrying a pairing secret. On successful pairing the host mints a durable device key. You are responsible for the trust placed in any device you pair.
  3. Updates. Spettro-Desktop has its own auto-update mechanism that checks for newer releases. Nothing is updated silently — you press the button.
  4. No tracking. Spettro-Desktop does not embed analytics, advertising or third-party trackers.

17. Spettro for macOS

Spettro for macOS is the native desktop application we distribute for macOS. It is built entirely for macOS using Swift and SwiftUI. It functions the same as Spettro-Desktop — it is a view over the CLI, which it runs as a subprocess via the Agent Client Protocol — but, unlike Spettro-Desktop, it is not based on Electron: it is a native app that leverages macOS-native frameworks. By installing and using Spettro for macOS you agree to the following:

  1. What it stores. Spettro for macOS locally stores the same types of data as Spettro-Desktop (user preferences, chat-session snapshots, paired-device records via the LAN relay) in macOS-native locations. It does not duplicate your API keys or any other secret held by the CLI.
  2. LAN phone relay. Like Spettro-Desktop, when you enable the LAN relay, Spettro for macOS advertises a local network service and shows a QR code for device pairing. You are responsible for the trust placed in any device you pair.
  3. Updates. Spettro for macOS has its own auto-update mechanism. Nothing is updated silently — you press the button.
  4. No tracking. Spettro for macOS does not embed analytics, advertising or third-party trackers.
  5. Native framework. Spettro for macOS is built entirely with Swift and SwiftUI, leveraging macOS-native frameworks. It is not based on Electron or any cross-platform framework.
